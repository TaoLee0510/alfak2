# Accuracy upgrade development benchmark

Start with [the final independent exact-division report](final_exact_review.md). Average point RMSE decreased at d0–d3, but all four paired confidence intervals include zero, some truth-family strata regress, and calibrated interval scores do not improve at every distance. The strict promotion gate did not pass; the joint candidate remains explicitly selected and the default pipeline remains `two_layer`.

This directory is independent of the pre-existing benchmark scripts. It does not restore deleted files or edit `R/benchmark-second-layer.R`.

The default pilot generates 24 paired datasets: three positive-rate landscape families (smooth, rough, sparse interaction), two independent landscapes each, two division-driven ABM trajectories per landscape and two count samples per trajectory. The entire four-chromosome copy-number domain 1–3 (81 nodes) is frozen for every method. The ABM has symmetric daughter changes, repeated division-associated mutation and removal of nonviable daughters; it uses no inference code.

All pilot landscapes are development/train. `config.R` reserves separate landscape seeds for calibration and test; they are not generated or opened by this pilot. Results must not be described as independent test accuracy.

```sh
Rscript validation/accuracy_upgrade/prepare_pilot.R /tmp/alfak2-accuracy-data
Rscript validation/accuracy_upgrade/run_pilot.R --data /tmp/alfak2-accuracy-data --output /tmp/alfak2-accuracy-results --model baseline --library /path/to/frozen-baseline-library
Rscript validation/accuracy_upgrade/run_pilot.R --data /tmp/alfak2-accuracy-data --output /tmp/alfak2-accuracy-results --model candidate --library /path/to/candidate-library --fit-args-rds /path/to/candidate-fit-arguments.rds
Rscript validation/accuracy_upgrade/report.R /tmp/alfak2-accuracy-results validation/accuracy_upgrade/pilot_review.md
```

Generate sealed calibration/test datasets only when the model is frozen, using `prepare_pilot.R --output /new/data/directory --split calibration` or `--split test`. These splits use different landscape seeds; do not mix them into development tuning. They have not been run in the initial pilot.

Formal validation protocol v2 uses `--backend gillespie` on independently reserved calibration/test landscapes. The original default `--backend tau_leap` data are retained as historical development/robustness results. See `protocol_v2.md`. `validate_simulation_backends.R` checks the beta-zero Yule mean against Monte Carlo uncertainty and tau small-step convergence. All generating-protocol metadata are retained so calibrated uncertainty cannot silently transfer between the two simulator protocols.

`prepare_pilot.R --output /tmp/alfak2-farfield --profile farfield` prepares a separate five-chromosome, 243-node support-limit probe. It deliberately has zero mutation and a founder-only population, guaranteeing distances d0–d5 without selecting seeds after inspecting results. Its role is to inspect prior-dependent uncertainty and output coverage when data cannot identify remote fitness, not establish successful remote inference.

`probe_scalability.R --output /tmp/alfak2-scalability.csv` writes a frozen graph-size plan for 4, 8, 12 and 22 chromosomes with covariance/Hessian memory lower bounds; it performs no fit. Add `--run-build --library /path/to/library` to measure graph construction only. This does not establish that end-to-end inference is feasible at those sizes.

Each model must run in its own R process because the shared library is named `alfak2`. Alternatively supply `--source /path/to/source --dll /path/to/alfak2.so`. Extra arguments are a named R list saved with `saveRDS()`. `--limit 1` times a first fit; `--ids id1,id2` selects datasets. Dataset results are cached and resumed, with incompatible caches recomputed. Use distinct model labels or output directories for different scientific candidates. Provenance records package/source path, R session, data and implementation checksums, scoring code and extra fit arguments.

`write_model_arguments.R /tmp/alfak2-model-arguments` writes the explicitly specified ablation, joint endpoint, joint division and five development prior-scale variants as RDS argument lists. Scale-grid variants multiply main, curvature, interaction, residual and edge standard deviations by 0.05/0.2/0.5/1/2 while retaining baseline SD 0.5. They are development candidates, not test-selected winners. Source/DLL, argument, dataset and scoring-code hashes are checked before reusing any cache. Parallel runs may add `--workers 3 --worker-index 1` (and separate processes for indices 2/3); worker CSVs have distinct filenames and the report merges them.

Primary metrics compare one t0-count-weighted observed-reference fitness contrast, fixed across every distance. No per-shell centering or truth-fitted affine map is used. `raw_rmse` is diagnostic only when methods use different physical/relative scales. Each exact distance has RMSE/MAE, gradient error and sign accuracy, complete prediction fraction, 50/80/95% contrast coverage, interval width and proper interval score. Complete contrast covariance is required for interval scores. Baseline covariance reconstruction is verified against its unchanged posterior means and diagonal variances before use. `all_distance_macro` equally weights distance strata; `all_node_micro` is also retained and explicitly labeled.

Paired comparisons average over ABM/sampling repeats within each landscape and resample independent landscapes. Six landscapes provide screening evidence only. An exhaustive claim about every distance requires more independent landscapes, scenarios and sealed-test evaluation. No HPC, commit or push is performed by these scripts.

Independent held-out counts are sampled from the frozen latent populations with seed `sampling_seed + 50000000`, at the original raw depths. Their per-cell predictive negative log score is reported using a declared 1e-12 probability floor; zero-probability hits are counted separately. These data never enter the fit. The report exports concise machine-readable summaries next to the report under `results/`; detailed nodes, per-dataset metrics, warnings and caches remain in the chosen output directory.

`analyze_endpoint_bma.R /tmp/scale-grid-results /tmp/alfak2-accuracy-data` analyzes cached endpoint prior-scale fits with uniform-prior marginal-evidence weights. The four-component primary mixture excludes scale 2; a five-component sensitivity analysis retains it. It uses no truth for weights and obtains contrast intervals from the actual Gaussian-mixture CDF. This development diagnostic is separate from validating a division-process mixture. The cached components do not retain predictive frequency vectors, so this diagnostic does not report a mixture held-out count score.

The argument writer also supplies 12 endpoint candidates separating basis SD multipliers (0.1/0.2/0.35/0.5) from residual and edge SD multipliers (0.2/0.5/1). `analyze_prior_pareto.R RESULTS OUTPUT.csv` reports each distance's RMSE and proper interval score, eight-dimensional Pareto membership, and nominal coverage deviations; it does not choose a winner using one overall average.

`prepare_depth_sensitivity.R PILOT_DATA OUTPUT` prepares 150/1000/5000-depth development scenarios from exactly the same latent frequency trajectories and seeds. It preserves the original 150-depth counts and fixes both the reference-distance strata and fitness contrast across depths, while separately recording the actual observed-support distance. These are conditional multinomial sampling scenarios, not new independent biological replicates. Calibration/test remain unopened.

`interval_calibration.R` supplies validation-only fit/apply functions for empirical signed standardized-error calibration. It requires an independent calibration split and exact model/scenario fingerprints, balances landscapes/datasets/nodes, leaves predictions and SDs unchanged, and labels unseen distances unvalidated. `test_interval_calibration.R` checks these behavioral constraints. This module is not a public default estimator and provides no finite-sample coverage guarantee.

`freeze_interval_calibration.R CAL_DATA CAL_RESULTS OUTPUT SEALED_TEST_DATA` requires complete model/target collections, refuses an already generated test manifest, writes immutable calibration RDS objects and quantile tables, and records their checksums plus proof that test generation had not begun. `apply_calibration_results.R DATA RAW_RESULTS FROZEN_OBJECTS` verifies those checksums and appends calibrated interval results without changing any point prediction or SD. Both the baseline and candidate receive their own calibration on the same independent split; the script separately exports paired comparisons against the calibrated baseline.

The formal experiment is archived under `results/protocol_v2/`: frozen calibration objects and checksums, candidate source/DLL manifest, compressed baseline/candidate source snapshots, all frozen dataset RDS files/manifests, run provenance and the exact formal scoring sources. Compiled DLLs are excluded from the source archives; their checksums and R/TMB session details are retained. Dataset manifests retain their original absolute paths; restore the recorded temporary directory layout or explicitly relocate manifest paths when reproducing the run.

`results/final_exact/node_matrices.rds` contains complete 81×48 truth/reference-distance and model point/SD/interval matrices. `group_completeness.csv` checks all model variants by truth family and landscape. d3 exists in 47/48 datasets, while every dataset has predictions for all 81 target nodes. Main-report means weight landscapes equally, matching the paired confidence intervals. The standalone `posterior_sampling.R` plus `test_posterior_sampling.R` validates true model-mixture sampling for experimental BMA; it is not substituted into the frozen fixed-prior formal experiment.
